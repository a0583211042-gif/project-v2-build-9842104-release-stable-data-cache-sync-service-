סינכרון שבועות — ערך מוסף, סח"י והסב"ש

לוח שבועות מרוכז

עיון לפי שבוע, לפי שם או לפי קטגוריה

👆 בחר שבוע מהרשימה למעלה כדי להציג את הפעילויות והמשתתפים.

לא נמצאו שמות מתאימים לחיפוש.

📖 הוראות שימוש

⏱️ זמני פעילויות

הסב"ש~30 דק'
הסב"ש חנת"ר~30 דק'
סח"י~30 דק'
ערך מוסף~5 דק'

🗓️ השבוע הנוכחי

המערכת מזהה אוטומטית את השבוע לפי התאריך ומתקדמת בכל יום ראשון.

  1. אם דילגתם על שבוע — לחץ על השבוע הרצוי
  2. בחלון שנפתח לחץ 📌 קבע כשבוע הנוכחי
  3. מכאן והלאה המערכת תמשיך לבד בכל יום ראשון

👀 3 דרכי צפייה

  • 📅 לפי שבוע — כל השבועות ברשת
  • 👤 לפי שם — כל אדם עם הפעילויות שלו
  • 🏷️ לפי קטגוריה — ערך מוסף / סח"י / הסב"ש

בטאבים "לפי שם" ו"לפי קטגוריה" יש תיבת חיפוש.

✏️ הוספת נושא

  • סח"י וערך מוסף — כפתור + הוסף נושא מתחת לשם
  • הסב"ש — הנושא קבוע, אין עריכה
  • עריכה — כפתור ✎ ליד הנושא
  • מחיקה — מחק את הטקסט ולחץ אישור

🎨 משמעות הצבעים

אין נושא יש נושא השבוע הנוכחי

🛠️ עריכת נתונים קבועים

פתח את הקובץ ב‑Notepad או VS Code ומצא:

  • אדם חדש — הוסף שורה ב‑PEOPLE
  • שבוע חדש — הוסף שורה ב‑WEEK_DATA
  • תיקון שם — ערוך רק ב‑PEOPLE, כל השבועות מתעדכנים

⚠️ חשוב לדעת

  • הנתונים נשמרים מקומית לכל מחשב
  • ניקוי היסטוריית הדפדפן ימחק נושאים שהוספת ידנית
  • שמור גיבוי לקובץ (ענן / מייל)

🆘 תקלות נפוצות

  • השינויים לא נשמרים → לא במצב פרטי/Incognito
  • שם שגוי → ערוך ב‑PEOPLE
  • שבוע לא מתקדם → קבע ידנית
  • לא רואה נושא שהוספתי → רענן עם Ctrl+F5
